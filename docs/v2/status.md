# Состояние VPN Chain Manager v2

Документ описывает актуальное состояние VPN Chain Manager v2. Для установки используйте `quick-start.md`.

## Что уже работает

- Двухузловая схема AM/RU:
  - AM работает как выходной AmneziaWG-сервер;
  - AM генерирует готовый клиентский конфиг для RU uplink;
  - RU использует этот файл как `awg1.conf`;
  - конечные клиенты подключаются к RU через `awg0`.
- Bootstrap-скрипт `scripts/vpnchain-bootstrap.sh`:
  - поднимает AM;
  - генерирует RU uplink config на AM;
  - применяет готовый `awg1.conf` на RU;
  - сохраняет `VPNCHAIN_SERVER_PUBLIC_KEY` и `VPNCHAIN_SERVER_ENDPOINT` в `/etc/vpnchain/vpnchain.env` на RU.
- SQLite-менеджер профилей:
  - `init-db`;
  - `peer add`;
  - `peer list`;
  - `peer show`;
  - `peer disable`;
  - `peer enable`;
  - `peer remove`;
  - `peer rotate`.
- Одноразовая генерация клиентских конфигов:
  - приватный ключ клиента не хранится в SQLite;
  - вывод внутрь Git-репозитория запрещён;
  - `PublicKey` и `Endpoint` сервера подставляются автоматически из env или CLI-флагов;
  - клиентские адреса по умолчанию выдаются из подсети RU `awg0` (`10.8.0.0/24`), чтобы совпадать с `server-ru/awg0.conf.template`.
- Локальный веб-интерфейс:
  - список профилей;
  - создание профиля;
  - включение/отключение/удаление;
  - отображение активности через `awg show`.
- Генерация ключей:
  - сначала используется host `awg`;
  - затем host `wg`;
  - затем резервный путь через `docker exec -i awg-ru awg`.
- Проверка репозитория:
  - `vpnchain repo-check` ищет приватные ключи, `.env`, SQLite-файлы и сгенерированные клиентские конфиги.

## Какой путь установки считать основным

Основной путь для новой установки:

1. AM: поднять exit-сервер.
2. AM: сгенерировать RU uplink config.
3. RU: применить `ru-awg1.conf` как `awg1.conf`.
4. RU: создать клиентские профили через CLI или веб-интерфейс.
5. RU: добавить публичный ключ клиента в слоты переменных окружения `CLIENT_PUB_KEY`, `CLIENT2_PUB_KEY`, … для активный Docker runtime.

Подробно: `docs/v2/quick-start.md`. Для агентской проверки свежей установки используйте `docs/v2/agent-install-checklist.md`.

## Ограничения текущего релиза

- SQLite хранит профиль клиента, но live Docker runtime всё ещё применяет peer'ы через слоты переменных окружения.
- Автоматический render/apply из SQLite в `awg0.conf` не является основным путём текущего релиза.
- Веб-интерфейс предназначен для локального или VPN-доступа, не для публичной публикации в интернет.
